DARK MODE / LIGHT MODE UPDATE
=============================

Added:
- Dark Mode / Light Mode switch on signed-in dashboards.
- Theme switch on guest/login pages.
- Theme preference is saved in the browser using localStorage.
- Theme choice remains after refresh, logout, and login on the same browser.
- Dark styling covers dashboard cards, tables, forms, modals, equipment cards, authentication pages, alerts, and responsive/mobile layouts.
- Theme-color metadata also changes with the selected mode.

No database migration is required for this UI feature.
